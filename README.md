# still. room

**still. room** is a minimalist online study and focus workspace for students.

Live site: https://still-room-original.onrender.com/

## What it does

- Focus Timer and Pomodoro sessions
- Online study rooms
- Study With Me workspace
- Tasks and habits
- Focus history and statistics
- Ambient sound and YouTube study setup
- Google sign-in for saving progress
